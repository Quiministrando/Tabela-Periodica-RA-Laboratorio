# Tabela Periódica RA - Laboratório

Versão experimental da Tabela Periódica Aumentada e Inclusiva.

Objetivo desta versão:
- modelo atômico interativo;
- prótons e nêutrons individualizados;
- formação de isótopos;
- formação de íons;
- animação das camadas eletrônicas;
- comparação entre elementos em realidade aumentada.
